Harmonia — getting started (30 seconds)

Harmonia is a MIDI generator, not a synth. The product is the notes.
Preview audio is a cheap sketch. If the preview piano sounds thin,
that is expected — load your own sounds.

The plugin shows as Harmonia. On disk the bundle is still
"Synthesia AI.vst3" until a dedicated rename. Same plugin.

This unsigned zip is the marketing trial. Generate and Drag MIDI
work with no key and no timer. Paid (ENFORCE) builds lock Generate
until you paste HRM-XXXXXXXX-CCCC. Drag MIDI never locks.

Install first (unsigned zip): see INSTALL.md in this folder.
macOS: right-click the .vst3 → Open. Windows: More info → Run anyway.
Then copy it into the system VST3 folder and rescan.

1. Insert Harmonia on a MIDI / instrument track (Live, FL, Reaper,
   Cubase, Studio One). Logic: VST3 wrapper only — no AU in this zip.
2. Pick a genre (or a Harmonia plan — genre · mood — in the combo).
3. Tap Generate. Five tracks: Chords (ch 1), Bass (ch 2), Synth (ch 3),
   Piano (ch 4), Drums (ch 10 / GM).
4. Drag the handle labelled "Drag MIDI into DAW" (bottom left) into
   your DAW — not the piano-roll.
5. Load YOUR piano, bass, and drums. Route ch 10 to a drum kit.

Sample / demo key (optional — this trial zip does not need one)
  Settings → paste HRM-XXXXXXXX-CCCC → Validate (or tap Paste).
  Spaces and a "License:" prefix are stripped. The key stays visible
  so you can check the checksum. Offline HRM- never leaves this machine
  and does not expire.
  Invalid: truncated paste / bad checksum. Re-copy the full HRM- line.
  Expired / disabled: Lemon HTTP only (not live). Offline HRM- never expires.
  Testers / operator mint before Lemon: from the repo run
    Tools/make_license_key.sh
  That prints one HRM-XXXXXXXX-CCCC. Email it, or paste it in Settings.

Unsigned build: Gatekeeper / SmartScreen will warn. Not malware.
Follow INSTALL.md and UNSIGNED_SMOKE.txt.

UNSIGNED_SMOKE.txt, LICENSE.txt.
