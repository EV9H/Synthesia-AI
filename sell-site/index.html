FAQ

Straight answers. No vaporware claims.

Is this a synth? The preview piano sounds cheap.

No. Harmonia is a MIDI generator for YOUR DAW sounds, not a synth and not a sample pack. Preview audio is a sketch so you can hear the MIDI shape. Drag the notes onto your piano, bass, and drums. A thin built-in piano is expected, not a defect.

Is this an AI that listens to audio?

No. Harmonia plans and writes notes. You hear them through whatever instruments you load in your DAW. Preview MP3s on this page are illustrative renders only.

What do I get after purchase?

A download link and a license key HRM-XXXXXXXX-CCCC for the VST3 (macOS / Windows). Settings → paste the key → Validate. Generate needs the key on paid builds. Drag MIDI and export always work, even before you paste it.

Generate asks for a key. Is it broken?

No — paid builds need the key before Generate writes a new clip. Tap Generate (it stays clickable) and Settings opens so you can paste HRM-XXXXXXXX-CCCC or hit Paste. Drag MIDI still works so you can audition a clip that is already on the piano roll.

macOS / Windows says the plugin is unsafe

Unsigned builds trip Gatekeeper and SmartScreen. That warning is expected until the developer signs the installer — it is not malware. Prefer the signed download from your receipt once it exists. The zip includes UNSIGNED_SMOKE.txt: right-click Open / More info → Run anyway, copy the .vst3 into the VST3 folder, rescan, Generate, drag MIDI.

Can I try it before paying? Is there a trial?

Yes. The unsigned zip is the trial: Generate and Drag MIDI work with no key and no timer. Use it in your DAW before Lemon checkout exists. Paid (ENFORCE) builds lock Generate until you paste HRM-XXXXXXXX-CCCC. Drag MIDI never locks.

Does the key work offline?

Offline HRM-XXXXXXXX-CCCC keys validate on this machine and never expire. They are not sent anywhere. Lemon keys need a validate URL (optional, not live yet). Genre templates work offline. Text-to-arrangement / Inspire need a network and an LLM key you supply.

My key says invalid or expired

Invalid HRM- usually means a truncated paste — copy the full HRM-XXXXXXXX-CCCC line (Settings → Paste). Offline HRM- keys do not expire. “Expired” / “disabled” is a Lemon HTTP status once checkout is live — ask for a new key or a refund through Lemon.

Do I need an internet connection?

Not for Generate, Drag MIDI, or an offline HRM- key. Text-to-arrangement and Inspire use a cloud LLM only if you turn that on. Genre templates work offline.

Which DAWs? What about Logic?

VST3 + dragged MIDI: Ableton Live, FL Studio, Reaper, Cubase, Studio One, and similar. Logic Pro has no native VST3 — use a VST3 wrapper, or wait for AU. This zip does not include AU.
